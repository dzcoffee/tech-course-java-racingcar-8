# java-racingcar-precourse

# 구현할 기능 정리

## 자동차 초기 설정

- 입력 값을 구분자에 따라 나눠 자동차 정하기
    - 입력 값 받기
    - 자동차 Class 만들기
    - 입력 값에 따른 자동차 배정 메서드 작성하기
- 자동차를 일괄적으로 저장하는 Class 만들기
    - 자동차의 전진 칸을 저장하는 Track Class 만들기

## 자동차 전진시키기
- 시도할 횟수로 자동차 전진시키기
    - 시도 횟수 입력받기
    - 무작위 값을 통해 자동차 전진시키기
- 시도 횟수동안 실행결과 출력하기
    - Track Class에 메서드 작성하기
    - 실형결과 출력메서드 작성

## 우승자 지정하기
- 시도 횟수에 맞게 끝나도록 설정하기
- 경주 게임 완료 이후 우승자 정하기
    - 우승자 찾고 출력하기
    - 여러 명일 경우 쉼표 이용해 구분하기

## 예외 찾기
- 자동차 이름 5자 초과 예외 처리
- 사용자 시도 횟수 입력 잘못된 문자 예외처리
